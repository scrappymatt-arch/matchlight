# YorAkka V3.9

## V3.9 changes

- Updates the brand line to **YOUR FOOTBALL. YOUR PICKS. YOUR WAY.**
- Adds a deliberate phone-first layout for My Matches so controls use less vertical space.
- Keeps list tabs and list actions compact while placing the six status totals on one row.
- Places tracker filters and Date on one row, with list status and update countdown directly beneath.
- Allows long team names to wrap to a maximum of two lines in Fixtures and My Matches without making rows unnecessarily taller.
- Keeps scores and add/remove controls in fixed columns so long names cannot overlap them.
- Updates the visible version and service-worker cache to V3.9.

## Deployment

Replace all GitHub Pages files with this package. The Cloudflare Worker is unchanged from V3.8, so it does not need redeploying. Keep the existing `API_FOOTBALL_KEY` secret.
