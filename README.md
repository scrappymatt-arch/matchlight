# YorAkka V3.28

## V3.28 changes

- Adds a Historical Results CSV tool inside the Fixtures page without adding another bottom navigation tab.
- Choose a From date and To date, then download completed results for all selected Favourite Leagues.
- Historical export columns are exactly: date, time, home team, home goals, away goals, away team.
- Uses the app time-zone setting for exported date and time.
- Shows export progress while YorAkka works through the selected leagues and seasons.
- Extends the protected Worker with a historical results endpoint and season-history data, so V3.28 requires a Worker redeploy.
- Retains the V3.27 two-step market picker, correct-score controls, goal alerts, injury-time clocks and fixture-position restoration.
- Updates the visible version, asset versions and service-worker cache to V3.28.
