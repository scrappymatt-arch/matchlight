# YorAkka V3.32

## V3.32 changes

- Adds fixture status filters beside the Historical Results CSV control: All, Fixtures, In Play and Results.
- All is the default. Fixtures, In Play and Results support multi-select, including any two together.
- Selecting all three specific filters automatically returns to All; clearing the last specific filter also returns to All.
- The Favourite Leagues notice now shows the number of games currently visible after filters/search are applied.
- Keeps all V3.31 features, including historical-results and team-list CSV export.
- Updates the visible app version, frontend asset versions and service-worker cache to V3.32.

## Deploy

Replace the GitHub Pages files with this release. The Cloudflare Worker is unchanged from V3.31, so it does not need redeploying.
