# YorAkka V3.21

## V3.21 changes

- Adds Double chance tracking: Home or draw, Home or away, and Draw or away.
- Adds Correct score tracking with home/away score selectors and common-score shortcuts.
- Correct-score selections show On target while live, Won at full time, remaining goals needed, or Lost as soon as either team exceeds the chosen score.
- Updates goal alerts, list totals, breakdowns and shared-list text for the new selection types.
- Updates the visible version and service-worker cache to V3.21.

Replace all GitHub Pages files with the contents of this package. The Cloudflare Worker is unchanged.
